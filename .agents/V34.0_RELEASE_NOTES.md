# Marcus Fleet V34.0 Release Notes

## Focus

V34.0 introduces the **Superpowers Discipline Layer**. It upgrades the public command surface to enforce strict engineering discipline: agents must clarify before planning, plan before code, use TDD for behavior changes, investigate root causes before fixes, review requirement compliance before code style, and avoid completion claims without fresh evidence.

## Executive Summary

- **Clarification-First Protocol**: Agents must ask questions when intent, scope, data, rollback, or verification is unclear before proceeding to planning.
- **No Placeholders**: Planning must be concrete; template placeholders are rejected.
- **RED-GREEN-REFACTOR**: Enforced test-driven development loop for behavior-changing tasks.
- **Evidence-Before-Claim**: Agents are blocked from claiming completion without verifiable, replayable evidence.
- **Root Cause Debugging**: Requires systematic debugging before proposing fixes for observed failures.
- **V34 Validator**: A new hard gate `validate_superpowers_discipline.py` is wired into preflight, postflight, and readiness checks to prevent discipline regressions.

## Major Changes

### 1. Superpowers Discipline Integration
All README-published slash command workflows (e.g., `/develop`, `/planning`, `/design`, `/quick_fix`) now embed the `Superpowers V34 Discipline` rules directly in their markdown contracts. This ensures that agents always operate under these strict behavioral constraints.

### 2. Upgraded Feature Templates
Feature generation templates (`spec-template.md`, `plan-template.md`, `tasks-template.md`, `verification-template.md`, `execution-brief-template.md`) now inject:
- A Clarification Ledger.
- Explicit V34 discipline gates.
- TDD task rules.
- Verification-before-completion enforcement.

### 3. Hardened Validation Gates
The new script `validate_superpowers_discipline.py` enforces the presence of V34 markers across the `.agents` folder. This script is fully wired into:
- Harness preflight and postflight scripts.
- Execution readiness checks.
- Document and workflow validation gates.
- `/marcus.routecheck`.

## Upgrade Notes

After installing or updating to V34, the new V34 constraints apply. Ensure you run:

```bash
python3 .agents/scripts/validate_superpowers_discipline.py --root .
python3 .agents/scripts/validate_command_surface.py --root .
python3 .agents/scripts/run_required_docs_gates.py --root . --mode auto
```

For existing brownfield projects, you may need to update active `spec.md` and `plan.md` artifacts to include V34 markers (like the Clarification Ledger) before execution readiness can pass.
