# Shared Motion & Physics Standards (`motion.md`)

1. **Duration Tokens**:
   * `--motion-fast`: `150ms` (Hover states, button active feedback).
   * `--motion-base`: `250ms` (Dropdown collapse/expand, modal overlay fade).
   * `--motion-slow`: `350ms` (Slide-over panels, page transition shells).
2. **Easing Functions**:
   * `--ease-out`: `cubic-bezier(0.16, 1, 0.3, 1)` (Entrance animations).
   * `--ease-in-out`: `cubic-bezier(0.4, 0, 0.2, 1)` (State transitions).
