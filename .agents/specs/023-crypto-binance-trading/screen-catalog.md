# Screen Catalog — 023-crypto-binance-trading

## Screen Inventory

### 1. `CRYPTO-001` — Live Trading Floor & Orderbook
* **Purpose**: Primary trading hub displaying BTC/USDT candlestick chart, depth orderbook bids (Green `#0ECB81`) & asks (Red `#F6465D`), and active tickers.
* **Layout**: Binance Navigation Bar + Candlestick Chart Viewport + Depth Orderbook + Quick Buy/Sell Drawer.
* **Key Actions**: `Select Pair`, `Filter Timeframe`, `Click Buy BTC`.

### 2. `CRYPTO-002` — Spot Order Execution Modal
* **Purpose**: Order entry form supporting Market and Limit Buy/Sell orders with percentage quick-select buttons.
* **Layout**: Binance Yellow Shell + Order Type Tabs (Market/Limit) + Amount Input + Percentage Slider ($25\%, 50\%, 75\%, 100\%$) + Yellow CTA Button.
* **Key Actions**: `Toggle Market/Limit`, `Adjust Percentage Slider`, `Confirm Order`.

### 3. `CRYPTO-003` — Trade History & Wallet Balances
* **Purpose**: View filled order logs, realized PnL, and spot wallet assets.
* **Layout**: Asset Summary Cards + Filled Orders Table + Real-time PnL Indicator.
* **Key Actions**: `Filter Asset`, `Export Trade Log`.
