A 32px selectable pill for filters, tags and quick choices — outline when idle, blue-tinted when active.

```jsx
<Chip active onClick={toggle}>Giao nhanh</Chip>
<Chip leadingIcon={<Icon name="AAddProperty1Line" size={16} />}>Thêm</Chip>
```

Variants: `active`, `disabled`, `leadingIcon` / `trailingIcon`, `image` (24px round thumbnail).
